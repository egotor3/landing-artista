# landing-artista

## Description
Página única en HTML y CSS para Cosmos Místico: astrología, numerología y mediumnidad. Incluye portada, navegación por secciones, textos para lectores de pantalla y datos Schema.org.

## Getting started
Abre `index.html` en el navegador.

## Structure
- `index.html` — portada, sobre mí, trayectoria y próximas presentaciones
- `styles.css` — presentación de la página

## Usage
Usa el menú para ir a Sobre mí, Trayectoria o Próximas presentaciones. También puedes escribir a mistico@cosmosmistico.es.
